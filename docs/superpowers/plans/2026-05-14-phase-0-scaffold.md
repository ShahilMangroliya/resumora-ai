# Phase 0 — Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the ResumeFit monorepo skeleton — a `uv` Python workspace plus a Next.js app — so `make dev` boots the FastAPI backend and the Next.js frontend together, and `make test` passes.

**Architecture:** A polyglot monorepo with `apps/` (deployable apps) and `packages/` (shared Python libraries). A `uv` workspace links the Python members (`apps/api`, `packages/pipeline`); the Next.js app in `apps/web` is self-contained. A root `Makefile` is the single command surface; `honcho` runs the two dev servers from a `Procfile`. No Turborepo — the repo is Python-majority with one JS app.

**Tech Stack:** Python 3.12, `uv` (workspace + deps), FastAPI, `uvicorn`, `pytest`, `httpx`, `ruff`, `honcho`, Next.js (TypeScript + Tailwind + App Router), Ollama (local LLM runtime).

**This plan is Phase 0 only.** Phases 1–8 from the design doc (`docs/superpowers/specs/2026-05-14-ai-pipeline-design.md`) each get their own plan.

## File Structure

Files created in this phase and their responsibility:

- `pyproject.toml` — `uv` workspace root; declares members, dev dependencies, `ruff` + `pytest` config. Non-package (orchestrator only).
- `.gitignore` — ignore Python/Node/env/MLflow artifacts (extends the existing one-line file).
- `README.md` — short project intro + how to run.
- `Makefile` — `install`, `dev`, `test`, `lint` targets. The single command surface.
- `Procfile` — process definitions for `honcho` (`api` + `web` dev servers).
- `packages/pipeline/pyproject.toml` — the `pipeline` library package metadata.
- `packages/pipeline/src/pipeline/__init__.py` — package marker + `__version__`.
- `packages/pipeline/tests/test_smoke.py` — smoke test: package importable.
- `apps/api/pyproject.toml` — the `api` app package metadata; depends on `pipeline` (workspace).
- `apps/api/src/api/__init__.py` — package marker.
- `apps/api/src/api/main.py` — FastAPI app with a `/health` endpoint.
- `apps/api/tests/test_health.py` — integration test for `/health`.
- `apps/web/` — Next.js app, generated by `create-next-app` (self-contained, own `package.json`).
- `docs/ollama-setup.md` — how to install Ollama and pull the dev model, with verification.

# Ollama Setup

Ollama is the local, open-source LLM runtime used for the extraction and

```bash
brew install ollama
```
