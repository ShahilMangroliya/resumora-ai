# Resumora AI

An open-source AI pipeline that scores a resume against a job description,
explains the fit, and suggests bullet-point rewrites — fully self-hosted,
no paid APIs.

- **Fit score (0–100)** from a fine-tuned DistilBERT + LoRA classifier
  hosted on the Hugging Face Hub.
- **Skill match report** — required and nice-to-have skills, matched
  vs. missing, via sentence-transformer embeddings.
- **Three reasons + three bullet rewrites** generated by a local Ollama
  LLM (Llama 3.2 / Qwen 2.5).

## Architecture

```
 Next.js (apps/web)
        │  POST /analyze   (multipart: resume file + JD text)
        ▼
 FastAPI (apps/api)
        │
        ├─ 1. Ingestion       PDF / DOCX / TXT → normalized docs
        ├─ 2. Extraction      Ollama → structured profiles
        ├─ 3. Scoring         DistilBERT + LoRA → fit score 0–100
        ├─ 4. Similarity      sentence-transformers → skill match
        └─ 5. Reasoning       Ollama → reasons + bullet rewrites
        │
        ▼
 JSON response → score dial, skill chips, rewrite cards
```

Stages 1–5 live in `packages/pipeline` as pure libraries. The API
orchestrates them and degrades gracefully — if Ollama is unreachable,
the score still returns, and the response carries a `warnings` array
explaining what was skipped.

## Quick start

### Prerequisites

- Python 3.12+ and [`uv`](https://docs.astral.sh/uv/)
- Node 20+ and npm
- [Ollama](docs/ollama-setup.md) running locally with `llama3.2:3b` pulled

### Install

```bash
make install
```

This runs `uv sync --all-packages` and `npm install` in `apps/web`.

### Run

```bash
make dev
```

Boots the API on <http://localhost:8000> and the web app on
<http://localhost:3000> together via `honcho`.

Open the web app, drop in a resume (PDF/DOCX/TXT) and a job description,
and submit.

### Test

```bash
make test                          # Python suite (213 tests)
npm --prefix apps/web test         # Web suite (22 tests)
```

### Lint

```bash
make lint
```

## Configuration

All API config is read from `RESUMORA_AI_*` environment variables.

| Var | Default | Notes |
|---|---|---|
| `RESUMORA_AI_SCORER_REPO` | `distilbert-base-uncased` | HF Hub repo for the fine-tuned scorer. Point at your trained model (e.g. `<user>/resumora-ai-distilbert-lora`). |
| `RESUMORA_AI_SCORER_DEVICE` | `cpu` | `cpu` / `cuda` / `mps`. |
| `RESUMORA_AI_MATCHER_DEVICE` | `cpu` | Sentence-transformer device. |
| `RESUMORA_AI_OLLAMA_URL` | `http://localhost:11434` | Where Ollama is reachable. |
| `RESUMORA_AI_OLLAMA_MODEL` | `llama3.2:3b` | Tag used for extraction + reasoning. |
| `RESUMORA_AI_OLLAMA_TIMEOUT` | `30.0` | Per-call timeout (seconds). |
| `RESUMORA_AI_CORS_ORIGINS` | `http://localhost:3000` | Comma-separated allowed origins. |
| `RESUMORA_AI_WARMUP_ON_STARTUP` | `false` | Set `true` in production so model-load failures surface at boot. |

Web app config (`apps/web/.env.local`):

| Var | Default |
|---|---|
| `NEXT_PUBLIC_API_URL` | `http://localhost:8000` |

## API

### `POST /analyze`

Multipart form:

- `resume` — file (PDF / DOCX / TXT)
- `job_description` — string

Returns `200 OK` with:

```json
{
  "score": { "value": 78, "label": "strong_fit", "probabilities": { ... } },
  "skill_report": { "required": [...], "nice_to_have": [...] },
  "reasoning": { "reasons": [...], "rewrites": [...] },
  "warnings": []
}
```

`skill_report` and `reasoning` are nullable — if extraction or reasoning
fail, the score still returns and `warnings` explains what was skipped.

Returns `400` if the resume can't be parsed.

### `GET /health`

```json
{ "status": "ok" }
```

## Training your own scorer

The model card and weights live on Hugging Face Hub. To train your own:

1. Open `notebooks/01_train_on_colab.ipynb` in Google Colab (T4 is enough).
2. Set `HF_USER` to your Hub username and authenticate.
3. Run all cells — produces `<HF_USER>/resumora-ai-distilbert-lora`.
4. Point the API at it:

```bash
RESUMORA_AI_SCORER_REPO=<HF_USER>/resumora-ai-distilbert-lora make dev
```

Synthetic data generation lives in `packages/training`; the gold eval set
lives in `data/gold/`. The training run logs to MLflow (`./mlruns/`).
